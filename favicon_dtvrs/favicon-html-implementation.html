Revisa la pestaña del navegador - deberías ver el isotipo dtvrs

Estructura de archivos requerida:

/
├── index.html (tu página)
├── favicon.svg
├── favicon-16x16.png
├── favicon-32x32.png
├── favicon-64x64.png
└── site.webmanifest (opcional)

Copiar a tu proyecto:

  1. favicon.svg → Raíz del proyecto
  2. favicon-32x32.png → Raíz del proyecto
  3. favicon-16x16.png → Raíz del proyecto
  4. Pega el código del <head> en tu HTML

Alternativa minimalista (solo SVG):

<link rel="icon" href="/favicon.svg" type="image/svg+xml">

Si necesitas forzar recarga (durante desarrollo):

<link rel="icon" href="/favicon.svg?v=1" type="image/svg+xml">
